# Desk

Durable records for the quick support team. Read `digest.md` first.

- `owner/` - owner-approved guidance, routing and capacity policy (only Phil's stated words)
- `portfolio/` - one record per family project
- `signals/` - every ingested statement, attributed (project, guidance, decision, observation, proposal)
- `work/<WO>/` - work order, attempts (prompts and agent output), validation logs, outcome
- `questions/`, `decisions/`, `departures/`, `runs/` (executive reviews)
- `capacity/` - local launch ledger and provider observations
- `digest.md`, `urgent.md` - the notification surface; `logs/` - detail
